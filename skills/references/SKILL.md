# Fiction References

This directory is a shared craft reference library for Fiction skills and agents. It exists as a skill wrapper so plugin hosts that validate every `skills/*` directory can ingest the plugin without treating the reference directory as malformed.

Do not use this as an entry point. Use the specific Fiction workflow skill for the task.
